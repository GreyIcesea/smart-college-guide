# 电脑选购指南

::guide-callout{type="tip"}
本文讨论的电脑仅限于**笔记本电脑**,需要参考台式电脑的选购与组装,可以咨询**河海大学计算机协会(QQ:906615489)**
::

::guide-callout{type="info"}

- **重型任务**:

  - 超多图层的专业 ps 制图,
  - 超多对象的 3D 建模
  - 剪辑时长>30min 的高清视频
  - 并行开启多个虚拟机
  - 数据量十万计的机器学习
  - 运行本地大模型
  - 游玩 3a 游戏(LOL,CS,4399 不算)

- **轻型任务**:
  - office 全家桶
  - 课内的 python/c/c++/java 学习
  - 4399
  - 看视频
::

### 电脑分类

- 轻薄本：对标轻型任务,续航很好,本体和电源适配器都很轻,没有续航焦虑

- 游戏本：对标重型任务,续航很差,本体和电源适配器都很重,建议一直插着电用

- 全能本：什么都想沾点，比轻薄本重,比游戏本弱,性价比不是很高,十分甚至九分不推荐!

### 参考意见

- cpu 与 显卡

  - CPU 推荐(2025.8)

    |-----|---------|----------|----------|----------|
    | 推荐程度 | 推荐购买 | 推荐购买 | 酌情购买 | 游戏本不推荐 |
    | 性能水平 | 性能最强 | 性能性价比 | 参差不齐 | 只推荐轻薄本使用 |

  - GPU 推荐(2025.8)
    | | 5090 | 5070ti | 5060 | 5050 |
    |-----|---------|----------|----------|----------|
    | 推荐程度 | 推荐购买 | **最推荐** | 推荐购买 | **绝对不推荐** |
    | 性能水平 | 性能最强 | 性能性价比 | 性能**完全够用** | 求求你别买电子垃圾 |
    ::guide-callout{type="warning"}
    **买新不买旧**
    ::
    ::guide-callout{type="caution"}

  1. 警惕"i9 级 cpu""魔改 4090"这样的诈骗商品
  2. 多数时候京东自营网购,比从线下"不够熟的熟人"手上拿货要好
  3. 绝对不要去电脑城
     ::

- 硬盘与内存:
  - 512g+16g:能满足基本需求
  - 1T+16g:可满足多数人的需求
  - 2T+32g:可满足最能折腾的人的多数需求
    ::guide-callout{type="tip" title="电脑卡顿的反思"}
    如果你的电脑卡顿,首先应该反思的是自己的 cpu 与显卡,然后是自己有多少垃圾软件,最后才是硬盘和内存
    ::
