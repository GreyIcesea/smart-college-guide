# 宿舍

::guide-callout{type="warning" title="床上用品购买"}

- **不建议**购买**学校**以及**推销人员**出售的卧具
- 如果家乡路途遥远,可以考虑邮寄,或是到南京来购买卧具
- 非常建议到线下选取卧具
::

::guide-callout{type="tip" title="床帘"}

- 可以使用全包式床帘
- 如果购买的床帘自带支架,建议拆下床位原装的床帘支架(需要工具:十字螺丝刀)
::

### 江宁

- 床规格:1.9m\*0.9m
- 四人寝,上床下桌,封闭阳台,独立卫浴
- 部分宿舍家具较旧
