### Q&A

::guide-callout{type="info" title="社团的作用?"}

1. 社长保研有一点加分,作为成员不会有保研加成
2. 和兴趣相投的人一起玩
3. 和别的学校的人一起玩
4. 获取学时

::

::guide-callout{type="info" title="参加哪些社团?"}

- 正常:按自己的爱好选择

- 卷王:全参加,但只在感兴趣的社团活跃,但是这样就能在每个社团的每个演出/活动中当志愿者/观众,快速累积学时(~~虾头喵~~)
  
::

::guide-callout{type="info" title="社团之间的实力?"}

有的社团是大社团,有单独的活动室和不同的部门,比如天央动漫社,也有小社团,平时活动比较少,没有独立的活动室。

::

::guide-callout{type="info" title="参加了学生组织还可以参加社团吗?"}

当然可以,不过据说,之所以学生组织招新比社团招新早,是因为学生组织干活多乐子少

但都市传说一般不可信。例如某院科协的某部门全是乐子，而我们同样呼吁为爱发电、勤劳干活的朋友（捞一捞打工人）

::
