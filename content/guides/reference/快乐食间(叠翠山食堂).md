# 快乐食间(叠翠山食堂)

快乐食间一共有两层

### 一层

::guide-details{title="牛肉汤."}
他家可以说是真正做到了物美价廉：有拆骨肉汤（虽然我从来没遇见过）意味着汤里有真材实料,特色的葱油饼外皮金黄酥脆,内里面香十足,十元左右就能解决战斗,几块钱的饼也够你撑过苦日子.

菜品选择一般是汤+粉丝+豆腐丝（干丝）+饼,自选调料种类丰富.拿到餐以后可以先喝汤,感受汤里面的肉香,用勺把豆腐丝粉丝和汤盛在一起一口吞下,感受丰富的口感,空口吃饼,感受饼里的面香和油香,吃了几块饼后你可能会感觉有点腻（这也是唯一的缺点）,可以用饼沾一下汤或者直接泡在汤里面香与肉香的结合真的让人欲罢不能.
::

::guide-details{title="麻辣烫"}
食间一楼的麻辣烫味道不错,而且调料种类齐全,将军山的就差很多了.骨汤,番茄,麻辣拌,口味相比都比较柔和,优于将军山.
::

::guide-details{title="卤面"}
没太多好说的,只是建议点餐时选择拌面,面是底料+面+卤料,汤面就是在底料里加一勺面汤,面会变得非常烫而且味道会淡一点,其他的就没什么好说的了.
::

### 二楼

叉烧饭味道不错,肉给的不算少,整体的肉香也很浓郁,推荐.

我选我味是自选称重售卖,种类非常丰富,味道也还不错.

不推荐芝士拌饭,酱料甜咸辣混搭.
