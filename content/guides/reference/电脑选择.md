# 电脑选择

开始前的**Q&A**

::guide-callout{type="info" title="大学需不需要买电脑?"}
需要,手机并不能为你干任何事
::

::guide-callout{type="info" title="买电脑花多少钱合适?"}
4000-9000,别搁那无限加预算了,谁不知道越贵的电脑越好,真推荐 3~5w 的笔记本,几个人买啊.建议哪怕是富哥预算也别超过 12000(对应轻薄本纯艺术品,对应游戏本 5080 显卡),玩个两年换个新的不是很好吗
::

::guide-callout{type="info" title="平板能不能替代电脑?"}
不能,如果你坚持可以,我的回复是:"胡扯!"
::

::guide-callout{type="info" title="我的专业电脑性能需求高不高啊?"}
不高,哪怕是计算机相关专业,课内也没有几个高性能的需求
::

::guide-callout{type="info" title="买 windows 还是买 mac?"}
买 windows,但并不反对你购买 mac,但是要先咨询自己的学长学姐
::

::guide-callout{type="info" title="宿舍能放多大的显示器?"}
江宁和金坛可以放下最大 27 寸的显示器(江宁放置上下空隙很小,容易磕碰).本部由于是上下床,所以桌子是共用的,取决于你的室友让不让你放那么大的东西
::
