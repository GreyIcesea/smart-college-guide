# 用电用水

::guide-callout{type="tip"}
有消息声称学校功率限制为 880w,但实际上没有做出限制
::

- 用电

  - 不论是吹风机还是洗衣机都可以在宿舍使用
  - 电力紧张时期,可能会在十月实行 23:00 后停电
  - 电费约**0.56 元/度**,夏天开空调每天用电大概 20 度.
  - 缴费
    - 微信公众号-河海大学计财处:必须先把钱充进一卡通,然后缴费,但是一卡通在一天里的某个时段是不可以充值的,所以**不推荐**
    - **微信公众号-河海大学小电助手**:可以通过微信支付缴费,可以查看每天的用电量,需要绑定自己的宿舍电表
      [电表绑定方法](https://mp.weixin.qq.com/s/86RCFfdSSlk8WBLYVcnXyQ)

- 用水
  - 河海大学用水是免费的,自来水是免费的,洗澡水也是免费的(~~除了我们谁能做到?!~~)
  - 开水打水点会设在宿舍各楼层走廊尽头或电梯井旁，用支付宝付款打水。
