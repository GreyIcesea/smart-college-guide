# 成绩与绩点计算

- 课程成绩公式(省流版)
  - $S=\sum a_i \cdot b_i$
    - $a_i$表示你的平时分,期中成绩,期末成绩
    - $b_i$表示平时分,期中成绩,期末成绩的比例系数,每门课都有所区别
    - 学分<3 的课程没有期中考试
- 课程成绩计算公式(懒人版)
  - 等待教务系统自动计算
- 单门课程绩点

| 课程成绩 | 绩点         |
| -------- | ------------ |
| [90,100) | 5.0          |
| [85,90)  | 4.5          |
| [80,85)  | 4.0          |
| [75,80)  | 3.5          |
| [70,75)  | 3.0          |
| [65,70)  | 2.5          |
| [60,65)  | 2.0          |
| [0,6)    | 不及格(重修) |

- 绩点公式(省流版):
  - $X = \frac{\sum a_i \cdot b_i}{\sum a_i}$
    - 当 $X$ 表示**推优绩点**, $a_i$ 与 $b_i$ 表示你**必修课**的学分与绩点
    - 当 $X$ 表示**出国绩点**, $a_i$ 与 $b_i$ 表示你**每门课**的学分与绩点
