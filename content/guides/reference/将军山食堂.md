# 将军山食堂

将军山对学生开放的一共有 3 层

### 一层

::guide-callout{type="info"}
米线/板面,快餐米饭,煎饼/手抓饼,民族餐厅,蜜雪和蛋糕店。
::

米线不错：香料味浓郁而不突出,只是米线必定是一坨,必须在汤里搅拌开让它吸收汤汁才好。

同一家店铺还有板面,与米线的汤汁应该是同款,额外带一颗鸡蛋。但是板面更推荐外卖“老翟板面”,牛油的加入让汤汁更加浓厚,十分美味。

拌面更推荐二层的面店

### 二层

::guide-callout{type="info"}
韩式拌饭,快餐,烤肉拌饭,面,汉堡。
::

::guide-details{title="面店"}
二层的麻酱拌面是特色菜品。浓厚的麻酱加上黄瓜丝和炸花生米,送入嘴中的时候麻酱味充斥着你的口腔给你带来无上的幸福。唯一的缺点可能就是醋没有柜台外面.麻酱拌面用的麻酱微微带一些甜口,开始会很好吃但到后面会变得有些腻。

汤面招牌是羊杂面,但是并不推荐：羊杂处理差点意思,腥味比较大.

炸酱面没有主料,分鸡蛋,肉和混合三种口味,一般比较咸,可以让阿姨少给点酱。

麻酱面组成一般是面+汤/麻酱+主料（鸡丝,酥肉之类）+配料（鸡蛋,豆干之类）

不推荐此窗口的任何西红柿鸡蛋类面品,因为从上面的组成来看,汤/麻酱主要是咸口,而西红柿鸡蛋算作主料且是纯甜口,不会因为你要了西红柿鸡蛋面而汤/麻酱,所以除非想尝试或非常喜欢甜咸口混搭口味,否则不推荐

其他的菜品较为普通,可以自行体验。
::

::guide-details{title="拌饭"}
二楼有两个拌饭,一个韩式拌饭一个烤肉拌饭.

韩式拌饭只吃过一次感觉一般.

烤肉拌饭挺好吃,一般是饭+主料+菜（选三样）,菜我比较喜欢加豆腐,咸香的饭加入嫩滑的豆腐碰撞出的反差感真是欲罢不能。
::

::guide-details{title="水饺"}
快乐食间也有一家卖水饺的,两家都很明显是速冻的.
将军山是按馅料和大小份卖的,食间是自选称重.
依据自由度推荐快乐食间的。
::

::guide-details{title="汉堡"}
单从汉堡来看的话,将军山的汉堡是不如食间的,食间的汉堡明显比将军山的要大,味道也相对好一些.

但将军山的炸食种类比快乐食间多,食间没有炸鸡腿鸡排之类.但如果只是想吃炸鸡建议外卖搜“彩虹炸鸡”,将军山炸鸡较为油腻。

将军山的可乐可能会更甜一些,而食间的可乐气泡更足,投稿者舍友说将军山的其他饮料还不错.
::

### 三层

::guide-callout{type="info"}
烤盘饭,麻辣烫,麻辣香锅,米线,烤鸭饭,面条等。
::

将军山三楼的麻辣烫非常不推荐，汤底有很明显很明显的科技的感觉，不如食间麻辣烫。

烤盘饭味道还不错，只是稍稍咸。米线味道一般，没有什么特点。

烤鸭饭不如食间，鸭腿根部经常烤成碳。

面条主要是卤面和拌面，不如楼下。

麻辣香锅没吃过不作评价。

炒饭炒面中规中矩。

有一家水煮肉片拌饭（盖饭）还不错，可以尝试一下。
