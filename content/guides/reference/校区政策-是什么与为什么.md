# 校区政策

### Q&A

::guide-callout{type="info" title="为什么要建新校区?"}

为了建设与发展新工科专业

::

::guide-callout{type="info" title="为什么新工科以外的专业也要去住一年?"}

与金坛的合约要求金坛校区的在校人数不能太少

::

::guide-callout{type="info" title="影响?"}

1. 搬家累(哼哼~啊啊啊啊啊啊啊啊啊啊啊)
2. 师资力量难以投送到金坛,所以一些专业的大二乃至大三课程下放到了大一(~~是哪个专业一年学了四大化学和四大力学呢,不知道啊不知道~~~~~)

::

### 你的四年会在哪个校区

所有人大一都在江宁校区,大二都在金坛校区,大三大四在学院所在校区上课.
